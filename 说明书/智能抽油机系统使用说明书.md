# 智抽云——智能抽油机监测与运行优化系统使用说明书

适用系统：智抽云 V1.1 课程设计 Demo  
文档日期：2026-11-17  
运行方式：本地 Windows + 浏览器

本说明书面向课程演示和本地单机使用，说明如何打开系统、模拟运行数据、查看诊断报警、使用一键优化方案、执行参数优化，以及查询和导出历史数据。

> **当前访问地址**
> 系统已在本机启动，请在浏览器中打开以下地址：
> <http://localhost:8501>

## 1. 30 秒快速开始

如果当前页面已经可以打开，直接进入第 2 章开始操作。如果浏览器提示无法访问，请在项目目录中启动服务。

### 1.1 启动系统

```powershell
cd D:\develop\smart_pump
.\.venv\Scripts\python.exe -m streamlit run app.py
```

也可以使用项目根目录的 `start.bat` 或 `一键启动.bat` 直接启动，脚本会自动准备虚拟环境、安装依赖并打开浏览器。

保持 PowerShell 窗口运行，等待终端显示本地地址。默认地址通常为 http://localhost:8501，然后复制到浏览器打开。

| 检查项 | 正确状态 | 说明 |
| --- | --- | --- |
| 终端窗口 | 保持打开 | 关闭终端通常会导致服务停止。 |
| 浏览器地址 | localhost 或 127.0.0.1 | 本机访问优先使用 localhost。 |
| 页面标题 | 智抽云 | 看到首页即表示启动成功。 |
| 顶部标识栏 | 显示井场、设备、工况、SIMULATION 与“在线” | 该栏位于每个页面顶部，用于确认设备与数据来源。 |
| 侧边栏 | 运行看板、运行监测、诊断中心、优化工作台、数据中心 | 共五个页面，通过侧边栏切换。 |

### 1.2 打开顺序

首次使用建议按“运行看板 → 运行监测 → 诊断中心 → 优化工作台 → 数据中心”的顺序操作。如果数据库中没有数据，看板会提示先生成模拟数据。

本机访问使用 http://localhost:8501。如需在同一局域网的其他电脑访问，请使用 http://运行系统电脑的局域网IP:8501，并确认 Windows 防火墙允许该端口。

## 2. 页面地图

| 页面 | 主要用途 | 你会看到什么 |
| --- | --- | --- |
| 运行看板 | 一屏掌握设备健康度与报警态势 | 健康度仪表、关键指标、运行趋势、报警时间线、工况构成、示功图 |
| 运行监测 | 生成四类模拟工况数据 | 工况模拟器、设备指标、指标趋势、连续规则命中、当前诊断、最新报警 |
| 诊断中心 | 查看规则证据与处置报警 | R01-R04 规则卡、证据链、报警台账表格、筛选检索、快捷处置 |
| 优化工作台 | 一键方案与冲次参数模拟 | 当前工况判定、三个一键优化方案及预计效果、参数微调、方案搜索 |
| 数据中心 | 筛选、统计和导出数据 | 日期/工况筛选、趋势图、报警统计、CSV 导出、PDF 运行报告 |

五个页面共享同一个 SQLite 数据库。页面之间不需要手动同步，切换页面后会读取最新数据。

## 3. 页面操作指南

### 3.1 运行看板

运行看板是系统默认首页，用于一屏查看设备健康度、关键指标和报警态势。该页面本身不生成数据，数据来自其他页面写入的同一数据库。

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 顶部标识栏 | 平台名、井场、设备编号、当前工况、SIMULATION、在线状态 | 每次打开页面都会显示，用于确认当前设备与数据来源。 |
| 关键指标 | 设备状态、电机电流、负载率、模拟产量、瞬时功率、累计能耗 | 取最新一条模拟采样。 |
| 运行趋势与健康度 | 负载/电流/产量/功率趋势、健康度仪表 | 展示最近若干条采样的变化。 |
| 报警态势与工况机理 | 报警时间线、工况构成、示功图 | 示功图为课程模拟曲线。 |
| 最近报警与快捷入口 | 最近事件列表、跳转到各功能页 | 点击快捷入口可直接进入对应页面。 |

如果是首次使用且数据库中没有数据，看板会提示先到“运行监测”生成第一条模拟数据。

### 3.2 运行监测

运行监测用于生成模拟采样和观察当前设备状态。每次点击“生成模拟数据”会新增一条运行记录，相当于一个 1 分钟采样点。

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 1 | 在“工况模拟器”中选择工况 | 可选择正常运行、电机过载、疑似供液不足、异常停机 |
| 2 | 点击“生成模拟数据” | 新增运行记录，指标卡、趋势和累计能耗随之更新 |
| 3 | 观察“当前诊断” | 正常时显示绿色状态；异常时显示规则、等级、原因和建议 |
| 4 | 查看“最近报警” | 显示最近报警的类型、等级、规则编号和处理状态 |

除了单条生成，页面还提供两种演示方式：

| 按钮 | 用途 | 适用场景 |
| --- | --- | --- |
| 单步演示 | 按固定脚本逐步生成下一条采样 | 边讲边演示，便于解释每一步诊断 |
| 一键完整演示 | 一次性生成 13 条采样（正常→过载→供液不足→停机→恢复） | 快速得到完整报警与恢复过程 |

一键脚本内置固定随机种子，重复执行可得到一致的演示结果。展开“查看一键演示脚本”可查看每一步的工况说明。

### 3.3 诊断中心

诊断中心读取最近的连续采样窗口。R01 和 R02 默认需要连续 3 条采样满足条件，因此前两条异常数据不会立即报警，第 3 条才会触发。

| 规则 | 触发条件 | 演示操作 |
| --- | --- | --- |
| R01 | 最近 3 条采样的电机电流或负载率连续超限 | 选择“电机过载”，连续生成 3 条数据 |
| R02 | 设备运行中，最近 3 条采样的模拟产量连续低于基线 80% | 选择“疑似供液不足”，连续生成 3 条数据 |
| R03 | 停机状态，或冲次和功率同时接近零 | 选择“异常停机”，生成 1 条数据 |
| R04 | 冲次超出 3-8 次/min 的演示合理范围 | 由边界参数或外部数据测试触发 |

页面上半部分展示规则证据链和当前诊断，下半部分是“报警事件日志”。报警日志采用表格形式，报警较多时也能快速区分和查找：

| 操作 | 说明 |
| --- | --- |
| 状态筛选 | 按“全部 / 未处理 / 处理中 / 已关闭”过滤 |
| 等级筛选 | 按“高 / 中 / 低”过滤 |
| 规则筛选 | 按 R01 / R02 / R03 / R04 过滤 |
| 关键词检索 | 可按报警类型、编号、处理人或备注搜索 |
| 表格排序 | 点击列头可按编号、时间、等级、状态等排序 |
| 选择事件 | 点击表格中任意一行，下方即显示该事件详情与处置区 |

表格列出编号、触发时间、规则、报警类型、等级、持续时间、峰值电流、峰值负载、处置状态和处理人。选中事件后，可以用三种方式处置：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 快捷按钮 | 点击“标记处理中”“标记已关闭”或“重置为未处理” | 一键修改状态，无需填写表单 |
| 编辑表单 | 修改状态、处理人、处理备注后点击“保存处置结果” | 状态为“已关闭”时必须填写处理人 |
| 状态保留 | 刷新页面或重启系统 | 处置状态仍会保存在数据库中 |

### 3.4 优化工作台

优化工作台使用简化模型演示调整冲次后的结果，不会控制真实设备。页面会先根据当前工况和诊断结果给出判定，再提供两个层次的优化操作。

**（1）一键优化方案**

系统按当前运行状态自动生成三个方案，每个方案都附带预计效果：

| 当前工况 | 推荐方案 | 三个方案导向 |
| --- | --- | --- |
| 正常运行 | 综合平衡 | 节能降耗 / 综合平衡 / 稳产增产 |
| 电机过载 | 降载保护 | 降载保护 / 温和降载 / 维持产量 |
| 疑似供液不足 | 供液适配 | 供液适配 / 节能观察 / 维持产量 |
| 异常停机 | 基线恢复 | 低冲次启机 / 基线恢复 / 快速提产 |

每张方案卡片显示目标冲次、方案评分、预计功率、日耗电节省和模拟产量及各自变化率。点击卡片下方的“一键应用此方案”即可载入参数，并展示预计效果明细表和优化前后对比图。停机工况下，预计效果以课程基线参数估算，页面会给出提示。

**（2）自定义参数模拟**

一键方案载入后可在“自定义优化参数”区微调当前冲次、目标冲次、当前功率和当前模拟产量，选择优化目标后点击按钮：

| 优化目标 | 演示重点 | 查看指标 |
| --- | --- | --- |
| 节能 | 优先观察功率和日能耗下降 | 优化前后功率、日能耗、产量变化率 |
| 产量 | 允许增加模拟功率以换取更高产量 | 产量增量与功率增量 |
| 综合平衡 | 在节能和产量之间折中 | 四项指标及系统建议 |

| 按钮 | 用途 |
| --- | --- |
| 单点模拟 | 按当前输入的一组参数计算一组优化前后结果 |
| 方案搜索与推荐 | 在 3—8 次/min 范围内枚举候选方案，过滤产量保留率不低于 85% 的方案，给出推荐与 Pareto 前沿图 |

点击“清除一键方案”可移除当前载入的方案。

### 3.5 数据中心

数据中心页面用于按日期和工况查询记录，并生成报告。选择日期范围或工况后，页面会同步更新运行趋势、报警统计和历史表格。

| 操作 | 说明 | 导出结果 |
| --- | --- | --- |
| 日期范围 | 筛选所选日期内的运行和报警数据 | 只导出筛选后的记录 |
| 工况筛选 | 可选正常、过载、供液不足、停机 | 运行数据 CSV 会使用当前筛选结果 |
| 导出运行数据 | 点击“导出运行数据 CSV” | running_data.csv |
| 导出报警记录 | 点击“导出报警记录 CSV” | alarm_data.csv |
| 生成运行报告 | 点击“生成运行报告 PDF”，再点击“下载运行报告 PDF” | 中文 PDF 运行报告 |

PDF 报告包含筛选周期摘要、当前诊断、报警事件和最新优化方案建议。如果先优化工作台生成了方案，报告会自动引用该方案。

CSV 使用 UTF-8 BOM 编码，可直接用 Microsoft Excel 打开。如果筛选结果为空，导出按钮会禁用，避免生成误导性的空文件。

## 4. 推荐的完整演示流程

| 顺序 | 页面 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 运行监测 | 保持正常运行，连续生成 3 条数据 | 设备状态正常，无报警 |
| 2 | 运行监测 | 选择电机过载，连续生成 3 条数据 | 第 3 条触发 R01 高等级报警 |
| 3 | 诊断中心 | 在报警台账中筛选 R01，点选该行并处理 | 报警状态变为“处理中”或“已关闭” |
| 4 | 运行监测 | 选择疑似供液不足，连续生成 3 条数据 | 第 3 条触发 R02 中等级报警 |
| 5 | 运行监测 | 选择异常停机，生成 1 条数据 | 触发 R03 高等级报警 |
| 6 | 运行监测 | 恢复正常运行并生成 1 条数据 | 最新状态恢复，历史报警仍保留 |
| 7 | 优化工作台 | 查看当前工况判定，点击推荐的一键方案 | 展示预计功率、能耗、产量效果 |
| 8 | 优化工作台 | 微调参数并执行单点模拟或方案搜索 | 得到不同的功率、能耗和产量方案 |
| 9 | 数据中心 | 筛选并导出运行/报警 CSV | CSV 可用 Excel 打开 |
| 10 | 数据中心 | 生成并下载运行报告 PDF | 得到包含诊断与优化建议的报告 |

> **演示时如何解释连续判断**
> 前两条异常采样只是连续窗口中的证据，不会立刻生成报警；第 3 条仍满足条件才形成事件，这样可避免单点波动造成误报。

> **演示时如何解释一键方案**
> 方案按当前工况自动生成，预计效果来自简化公式，用于展示“辅助决策”的思路，不代表真实设备调整后的实际结果。

## 5. 数据保存与重置

### 5.1 数据保存在哪里

运行记录、报警和处理状态保存在 D:\develop\smart_pump\data\pump.db。刷新页面或重新启动应用不会清空数据。

### 5.2 如何重新开始演示

先停止应用，再备份 data\pump.db，然后删除或移动该文件。重新启动后系统会自动创建空数据库和演示设备记录。不要在应用运行中删除数据库。

```powershell
Copy-Item data\pump.db data\pump_backup.db
Remove-Item data\pump.db
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 6. 常见问题

| 现象 | 原因 | 处理方法 |
| --- | --- | --- |
| 浏览器无法访问 localhost:8501 | 服务未启动或终端已关闭 | 在项目目录重新执行启动命令，并保持终端打开 |
| 终端提示端口被占用 | 8501 已被其他程序使用 | 使用终端显示的新地址，或关闭占用端口的程序 |
| 页面提示暂无运行数据 | 数据库为空 | 先进入运行监测，点击生成模拟数据 |
| 异常数据生成 1-2 条仍未报警 | R01/R02 使用了连续窗口 | 继续生成第 3 条同类异常数据 |
| 第 4 条异常没有新报警 | 同一连续事件已去重 | 这是预期行为；恢复正常后再次越限会创建新事件 |
| 报警台账里找不到某条报警 | 当前筛选条件过窄 | 将状态、等级、规则恢复为“全部”，并清空关键词 |
| 点击表格行后下方没有切换到对应事件 | 该行不在当前筛选结果内 | 重新点击可见行；筛选变化后默认选中第一条 |
| 关闭报警时提示填写处理人 | 关闭状态要求留下责任人 | 在编辑表单中填写处理人后再保存 |
| 一键方案点击后没有变化 | 当前数据库无运行数据 | 先到运行监测生成一条模拟数据 |
| 方案搜索提示产量需大于 0 | 停机工况产量为 0，无法搜索 | 使用一键方案中的“基线恢复”，或恢复正常运行后再搜索 |
| 无法导入 pandas 或 streamlit | Python 环境或依赖不完整 | 使用项目 .venv 中的 Python 执行命令 |
| 历史筛选结果为空 | 所选日期或工况没有数据 | 扩大日期范围或选择“全部工况” |
| CSV 中文乱码 | 使用了不支持 UTF-8 BOM 的工具 | 优先使用 Excel 打开，或重新导出 |

## 7. 使用边界

本系统是课程设计 Demo，全部运行数据由软件模拟生成。诊断阈值、报警规则和优化公式均为演示假设，不连接真实传感器，不具备现场控制、联锁或工业级告警能力。

界面采用接近油气生产管控台的呈现方式，仅用于提升演示表达效果，不代表系统已接入真实 SCADA 或生产数据。

> **安全提示**
> 系统输出仅用于课程演示和功能展示，不得作为真实油田生产、设备调整或安全决策依据。
